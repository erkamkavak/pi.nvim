*pi.txt*  Neovim plugin for the pi coding agent

==============================================================================
pi.nvim                                                                *pi.nvim*

Neovim plugin for the pi coding agent. Provides a LazyGit-like interface
with split panels for session management and change tracking.

Features:
- Session sidebar with pinned sessions
- Toggleable changes panel showing last turn
- Session switching via RPC protocol
- Pinned sessions persisted to disk

==============================================================================
Setup                                                                  *pi.setup*

    require("pi").setup({opts})

Options:                                                      *pi-config-options*
    pi_cmd                  (string)  Path to pi command. Default: "pi"
    sidebar_width           (number)  Sidebar width in columns. Default: 35
	    changes_width           (number)  Changes panel width. Default: 50
	    changes_open_by_default (boolean) Open changes on start. Default: false
	    diff_highlight          (table)   Optional syntax-highlighted diffs:
	                                      enabled=true, install="never"
	    auto_start              (boolean) Auto-start pi. Default: false
	    session_dir             (string?) Session dir override for current cwd
	    chat_max_messages       (number)  Render cap for chat history. Default: 150
	    chat_max_chars_per_message
	                            (number)  Per-message char cap. Default: 4000
	    ui_margin_cols          (number)  Outer horizontal margin. Default: 2
	    ui_margin_rows          (number)  Outer vertical margin. Default: 1
	    keymaps                 (table)   Keybinding overrides (see |pi-keymaps|)

Diff syntax highlighting is optional. Install dependencies manually with:
    cd lua/pi/changes/highlight && npm ci
or set diff_highlight.install to "prompt" or "auto".

Keymaps:                                                        *pi-keymaps*
    toggle_sessions       Toggle session sidebar (default: <leader>ps)
    chat_command_palette  Open command palette in chat (default: ?)
    chat_command_palette_insert
                          Open command palette in input (default: <C-p>)
    sidebar_select         Select session (default: <CR>)
	    sidebar_toggle_pin     Toggle pin (default: P)
	    sidebar_delete         Delete session (default: d)
	    sidebar_rename         Rename session (default: r)
	    changes_toggle         Toggle changes (default: <C-c>)
	    chat_tool_nav_toggle   Toggle tool navigation mode (default: gt)
	    chat_tool_next         Next tool call (default: j)
	    chat_tool_prev         Previous tool call (default: k)
	    chat_tool_open_file    Open selected tool call file (default: o)
	    chat_tool_open_diff    Open selected tool side panel: diff for edits, terminal for bash (default: d)
	    prompt_send            Submit prompt (default: <C-j> for multi-line)

==============================================================================
Commands                                                          *pi-commands*

:PiStart                                                *:PiStart*
    Start the pi RPC process.

:PiStop                                                 *:PiStop*
    Stop the pi RPC process.

:PiSessions                                             *:PiSessions*
    Toggle the session sidebar.

:PiChanges                                              *:PiChanges*
    Toggle the last-turn changes panel.

:PiPrompt {msg}                                         *:PiPrompt*
    Send a prompt to pi.

:PiStatus                                               *:PiStatus*
    Show pi status.

:PiNewSession                                           *:PiNewSession*
    Create a new session.

Slash commands in chat input are handled locally where supported:
    /model /new /resume /session /name /compact /copy /export /fork /quit /hotkeys
Unsupported built-in slash commands are not forwarded to the LLM.

@ file completion in input bar:                                   *pi-at-completion*
    The input bar supports @-prefixed file path completion. Type @ followed by
    a partial file path to get file/directory suggestions from the current
    working directory. Directories are listed first and end with /. Supports
    relative paths, absolute paths, and ~/ for home directory.
    
    Keymaps while typing:
      <Tab>         Trigger completion (or accept selected item)
      <S-Tab>       Previous completion item
      <C-n> / <C-p> Next / previous item
      <C-y>         Accept selected item
      <C-e>         Cancel completion
    
    Examples:
      @src/        - browse files in ./src/
      @            - list all files in cwd
      @~/projects  - browse in ~/projects
      @../         - browse parent directory

Input bar behavior:                                              *pi-input-bar*
    The input bar is multi-line (auto-sized based on terminal height, 25% of
    available rows, min 3, max 8):
      - <CR> inserts a newline
      - <C-j> submits the prompt (configurable via prompt_send keymap)
      - <Esc> clears the input and navigates to chat
      - @ triggers file completion automatically

==============================================================================
API                                                                  *pi-api*

pi.setup({opts})                                                  *pi.setup()*
    Configure the plugin. See |pi-config-options|.

pi.start()                                                        *pi.start()*
    Start the pi RPC process.

pi.stop()                                                         *pi.stop()*
    Stop the pi RPC process.

pi.toggle_sessions()                                     *pi.toggle_sessions()*
    Toggle the session sidebar.

pi.toggle_changes()                                       *pi.toggle_changes()*
    Toggle the changes panel.

pi.prompt({msg})                                                 *pi.prompt()*
    Send a prompt to pi. If {msg} is empty, opens an input prompt.

pi.status()                                                      *pi.status()*
    Show pi status information.
